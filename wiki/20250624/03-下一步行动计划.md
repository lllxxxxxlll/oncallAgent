## 阶段二：改造 test 代码加深理解（下周）

### 练习 1：加 Lambda 节点打印切分数量
在 Splitter 和 Indexer 之间插入一个 Lambda 节点，打印：
- 文档被切成了多少个 chunk
- 每个 chunk 的前 50 个字符

**学到什么**：Lambda 的签名怎么写、InputKey/OutputKey 怎么和上下游对齐。

### 练习 2：把 `any` 改成具体类型
```go
// 改前
func BuildKnowledgeIndexing(ctx) (compose.Runnable[any, any], error)

// 改后
func BuildKnowledgeIndexing(ctx) (compose.Runnable[document.Source, []string], error)
```

**学到什么**：泛型类型安全的体验，改了后 IDE 对 `runner.Invoke(ctx, source)` 的参数和返回值都有补全。

### 练习 3：对比流式 vs 非流式
```go
// 非流式（当前）
result, err := runner.Invoke(ctx, source)

// 流式
streamReader, err := runner.Stream(ctx, source)
for {
    chunk, err := streamReader.Recv()
    if err == io.EOF { break }
    // 处理 chunk
}
```

**学到什么**：哪些节点支持 Stream？Indexer 支持吗？不支持时 Graph 怎么处理？

### 练习 4：加错误处理
- Loader 传入不存在的文件路径 → Graph 返回什么错误？
- Embedding API key 错误 → 报错在哪一层？
- 加 `OnErrorFn` 回调捕获错误
